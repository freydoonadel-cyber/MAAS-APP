# تصمیم‌های ثبت‌شده پروژه MAAS

- اپ فعلاً فقط برای کاربران ۱۸ سال به بالا عرضه می‌شود.
- حساب زیر ۱۸ سال پذیرفته نمی‌شود.
- Verified اختیاری است.
- کاربران می‌توانند نام عمومی انتخاب کنند.
- تبدیل عکس به 8-bit باید Pixel Art حرفه‌ای باشد، نه Pixelation ساده.
- ارتباط مستقیم MAAS Runner با Chat Roomها در مرحله بعد طراحی می‌شود.
- این ارتباط شامل دعوت از داخل چت، رویدادهای Room، بازار شهری و همکاری گروهی خواهد بود.
