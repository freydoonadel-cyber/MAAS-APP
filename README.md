# MAAS v0.1 Foundation

این نسخه اولین پایه واقعی و قابل توسعه پروژه MAAS است.

## اجرا بدون نصب
فایل `index.html` را با مرورگر باز کنید.

## اجرای توسعه حرفه‌ای
1. Node.js را نصب کنید.
2. در پوشه پروژه اجرا کنید:
   `npm install`
3. سپس:
   `npm run dev`

## اجزای این نسخه
- رابط اولیه Responsive
- سیستم Module Navigation
- LocalStorage State
- PWA Manifest
- Service Worker
- Vite configuration
- ساختار استاندارد Assets و Documentation

## وضعیت
این نسخه هسته Foundation است و هنوز شامل Backend، Chat واقعی، نقشه واقعی یا بازی کامل نیست.
